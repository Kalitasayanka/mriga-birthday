# Birthday Celebration & Heartfelt Letter 🎂✨

A warm, interactive 3D birthday celebration and thoughtful confession letter website handcrafted with React, Three.js, and Web Audio.

## 🌟 Highlights & Features

- **Interactive 3D Scene**: Custom 3D Birthday Cake with flickering candles, floating balloons reacting gently to mouse movement, twinkling stars, and floating gift box powered by `@react-three/fiber` and `@react-three/drei`.
- **Bootstrap 5 Integrated**: Built using Bootstrap responsive container, flexbox utilities, badges, and card architecture, paired with warm dark glassmorphism.
- **Swipe-First Interactions**:
  - **Swipe Cards to Flip Letters 👈 👉**: In the letter reader, swipe left or right with your finger to seamlessly flip between letters with real-time drag physics, rotation, and swipe pagination dots.
  - **Horizontal Envelope Deck**: Envelopes can be swiped horizontally on mobile like a carousel card deck.
  - **Swipe to Blow Candles 🕯️**: Drag your thumb across the interactive golden slider track to blow out the 3D candles and trigger celebratory confetti!
- **Make a Wish & Relight**: Interactive candle blow-out with sound effects and wish reveal banner.
- **URL Personalization**: Easily customize the recipient and sender names via URL query parameters (e.g., `?to=Prity&from=Sayanka`) or using the built-in "Share / Edit" modal in the top bar.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Production build
npm run build

# Run linter (oxlint)
npm run lint
```
